# Hackathon submission checklist

**Official deadline:** Meta's event page lists project submissions due **November 4, 2026, at 9:00 p.m. ET**. On that date this is **9:00 p.m. in Bogotá**. The page says dates can change and changes will be posted there; no extension was listed when checked November 4. Confirm the live event page and the actual authenticated submission form before submitting.

Meta's public page confirms the Indie Developer and Startup tracks and the “Build for Your World” and “Push the Frontier” themes. The detailed form and field limits were not publicly readable during this review. See [official event page](https://dev.meta.ai/events/global-hackathon). Do not assume this checklist is an official form schema.

## Prepared in the repository

- [x] Entire root README in English and aligned with the current Muse-only product path.
- [x] Paste-ready project descriptions and technical claims in [`../../SUBMISSION.md`](../../SUBMISSION.md).

- [x] Evidence-based impact statement in [`IMPACT.md`](IMPACT.md).
- [x] Reproducible synthetic English demo command and CSV noted in the README and video script.
- [x] Final readiness report drafted; update its test count and Git commit after verification.

## Project owner actions before submission

- [ ] Sign in to the official event portal and confirm the submission form is open and the deadline/fields shown there.
- [ ] Select the correct track based on the actual applicant/team and confirm eligibility under the official rules.
- [ ] Record the demo with fictional data; do not use a fabricated live model response.
- [ ] Upload the video and replace the URL placeholder in `SUBMISSION.md` with the real link.
- [ ] Paste the submission copy into the actual form, obeying its live field limits and required disclosures.
- [ ] Confirm that the public repository is accessible to judges and that its license status is understood.
- [ ] Review the final form for accurate team identity, product claims, and links.
- [ ] Complete and submit the official form before the portal deadline. Submission has not been performed by this agent.

## Do not claim without new evidence

- [ ] A public live deployment or production SaaS.
- [ ] Complete WhatsApp history, current successful outbound delivery, automatic replies, bookings, or verified payments.
- [ ] A production Muse accuracy/precision score, revenue impact, or independent customer validation.
- [ ] That a local demo or a historical dated test proves current external service availability.
